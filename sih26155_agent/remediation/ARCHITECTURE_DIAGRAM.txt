╚══════════════════════════════════════════════════════════════════════════════════╝

  Candidate Config
        │
        ▼
  ┌──────────────────────────────────────────────────────────────────┐
  │  GATE 1: SYNTAX VALIDATION                                       │
  │  ─────────────────────────                                       │
  │  • Parse candidate configuration                                 │
  │  • Check for syntax errors, unbalanced braces                    │
  │  • Validate command structure                                    │
  │                                                                   │
  │  Result: ✓ PASS / ✗ FAIL                                        │
  │  Block: YES if failed                                            │
  └─────────────────────────┬────────────────────────────────────────┘
                            │ PASS
                            ▼
  ┌──────────────────────────────────────────────────────────────────┐
  │  GATE 2: TARGET RESOLUTION                                       │
  │  ────────────────────────                                        │
  │  • Re-audit candidate configuration                              │
  │  • Compare with original audit results                           │
  │  • Verify target violations: FAIL → PASS                         │
  │  • Track unresolved violations                                   │
  │                                                                   │
  │  Result: ✓ PASS if all targets resolved / ✗ FAIL if not        │
  │  Block: YES if any target unresolved                             │
  └─────────────────────────┬────────────────────────────────────────┘
                            │ PASS
                            ▼
  ┌──────────────────────────────────────────────────────────────────┐
  │  GATE 3: REGRESSION AUDIT                                        │
  │  ───────────────────────                                         │
  │  • Compare before/after pass/fail counts                         │
  │  • Detect new failures introduced by fixes                       │
  │  • Identify improvements vs regressions                          │
  │  • Flag severity changes                                         │
  │                                                                   │
  │  Result: ✓ PASS if no regressions / ✗ FAIL if new failures     │
  │  Block: YES if any regression detected                           │
  └─────────────────────────┬────────────────────────────────────────┘
                            │ PASS
                            ▼
  ┌──────────────────────────────────────────────────────────────────┐
  │  GATE 4: SECURITY INVARIANTS                                     │
  │  ──────────────────────────                                      │
  │  • Verify critical controls still satisfied:                     │
  │    - CIS-MGMT-01 (SSH enabled)                                   │
  │    - CIS-MGMT-02 (SSH version 2)                                 │
  │    - CIS-AUTH-01 (Authentication required)                       │
  │    - CIS-AUTH-02 (Strong passwords)                              │
  │    - CIS-CRYPTO-01 (Strong crypto)                               │
  │  • Ensure no security degradation                                │
  │                                                                   │
  │  Result: ✓ PASS if all invariants held / ✗ FAIL if violated    │
  │  Block: YES if any invariant weakened                            │
  └─────────────────────────┬────────────────────────────────────────┘
                            │ ALL GATES PASSED
                            ▼
  ┌──────────────────────────────────────────────────────────────────┐
  │  PROMOTION GATE                                                  │
  │  ─────────────                                                   │
  │  • Check for critical rule modifications                         │
  │  • Require human approval if needed                              │
  │  • Generate promotion record                                     │
  │                                                                   │
  │  Decisions:                                                      │
  │  ✓ APPROVED  → Copy to output/fixed/                           │
  │  ⏸ DEFERRED  → Wait for human review                           │
  │  ✗ REJECTED  → Blocked (validation failed)                      │
  └──────────────────────────────────────────────────────────────────┘
